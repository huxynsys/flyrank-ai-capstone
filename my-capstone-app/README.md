# My Capstone App

## Overview
This project is an AI-assisted capstone project for the FlyRank internship track. It features a profile settings form that allows users to update their personal information.

## Project Structure
```
my-capstone-app
├── index.html       # HTML structure for the profile settings form
├── styles.css       # CSS styles for the form
├── script.js        # JavaScript functionality for form validation and submission
└── README.md        # Project documentation
```

## Getting Started

### Prerequisites
- Ensure you have Node.js installed on your machine.
- A modern web browser for testing the application.

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd my-capstone-app
   ```

### Usage
1. Open `index.html` in your web browser to view the profile settings form.
2. Fill in the required fields: Name, Email, and Password.
3. Click the "Submit" button to save your changes.

### Features
- User-friendly interface with clear input fields.
- Basic form validation to ensure correct data entry.
- Responsive design for accessibility on various devices.
